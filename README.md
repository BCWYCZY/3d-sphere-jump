# 3D 轨道跳跃

一个基于 Three.js 的 3D 颜色匹配网页小游戏。

## 玩法

- 球体在三车道轨道上自动弹跳
- 使用 `←` `→` 方向键（或 `A` / `D`）切换车道
- 每次弹跳必须落在与目标颜色匹配的方块上
- **注意**：红色的「危险方块」不能踩，否则立即失败
- 移动端：左右滑动屏幕或点击左右半屏切换车道

## 特性

- Three.js 3D 渲染，真实重力物理引擎
- Web Audio API 实时合成音效（铃铛/钢琴/吉他）+ 程序化背景音乐
- 碰撞方块下陷缓冲 + 同色涟漪扩散动画 + 命中粒子爆发
- 球体拖尾、屏幕震动、红/绿全屏闪光反馈
- **连击系统**：连续命中提升倍率（最高 8 倍）
- **难度递升**：存活越久，方块间距越大、危险方块越多
- **成就系统**：7 项成就，解锁时弹出提示
- 暂停功能（`P` / `Esc` / 右上角按钮）
- 阶段式积分系统 + 存活时间奖励
- 六种背景风格切换 + 粒子特效
- localStorage 历史记录排行榜 + 最佳连击
