# 3D 轨道跳跃

一个基于 Three.js 的 3D 颜色匹配网页小游戏。

## 玩法

- 球体在三车道轨道上自动弹跳
- 使用 `←` `→` 方向键切换车道
- 每次弹跳必须落在与目标颜色匹配的方块上

## 特性

- Three.js 3D 渲染，真实重力物理引擎
- Web Audio API 实时合成音效（铃铛/钢琴/吉他）
- 碰撞方块下陷缓冲 + 同色涟漪扩散动画
- 阶段式积分系统 + 存活时间奖励
- 四种背景风格切换 + 粒子特效
- localStorage 历史记录排行榜
